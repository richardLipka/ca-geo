# apps

Web applications (Vite + TypeScript). Each app is bilingual (cs/en) with all user-facing
texts in translation catalogues.

| App | Purpose | Status |
|---|---|---|
| `historic-mapper/` | Georeference historical maps of Plzeň and link buildings in views, drawings and engravings to map positions (data preparation for a historical town model) | working tool, standalone package |

CA demos will follow once the engine exists (npm workspaces, see `CLAUDE.md`).
