# Decisions (ADR)

Architecture and scope decisions recorded as ADRs (Architecture Decision Records).

- File name: `NNNN-short-title.md` (four-digit sequence number, kebab-case title).
- Template: `docs/templates/adr.md`.
- An accepted ADR is not rewritten; a change of mind is a new ADR that supersedes it.
