# Review

Evaluation and cross-cutting analysis of the candidate phenomena.

| File | Content |
|---|---|
| `criteria.md` | Evaluation criteria, 1–5 scale, weights |
| `evaluation-matrix.md` | Scores of all longlist items, grouping into core / extension / out of scope |
| `shared-components.md` | Building blocks recurring across models (basis for the core architecture) |
| `data-needs.md` | Data layers needed by the selected models, with candidate sources |
| `open-questions.md` | Open questions for the literature phase, with search keywords |

Files are added step by step during the exploratory phase.
