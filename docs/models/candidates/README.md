# Candidate model cards

One file per candidate model, named `<id>.md`, where `<id>` is the identifier from the
longlist (`docs/brainstorm/longlist.md`), written in kebab-case.

Cards are created from `docs/templates/model-candidate.md` for models in the *core* and
*extension* groups of the evaluation (`docs/review/evaluation-matrix.md`).

A card describes an idea, not a validated model: literature is marked `TODO(literature)`
and unverified facts "to be verified".
